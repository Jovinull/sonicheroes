Tools and projects we build on

decomp-toolkit

Analysis, splitting and linking of GameCube executables and RELs.

 objdiff

The byte-by-byte diff every match is checked in.

 dtk-template

The project template this repository started from.

 wibo

Runs the original Windows compilers on Linux and macOS.

 decomp.dev

Tracked the project's progress from July to October 2026.

 ByteMatch

Tracks the project's progress today.

 Heroes Hacking Central

PC disassembly, Heroes.SDK and file-format tools that help name functions and structures.

 HeroesPowerPlant

GameCube-aware level editor and format research.

 RenderWare3Docs

EA's public RenderWare white papers and user guide.

 librw

Clean-room RenderWare implementation, used as a file-format reference.

 Sewer56's Sonic Heroes research

Background on the game and its cross-platform symbols.
